# \# Sistema Web Empresarial de Gestão de Biblioteca

# 

# \## 1. Descrição do Projeto

# 

# O Sistema Web Empresarial de Gestão de Biblioteca é uma aplicação web desenvolvida para facilitar a gestão de livros, leitores, empréstimos e devoluções.

# 

# O sistema permite centralizar as informações da biblioteca, reduzir o uso de registos manuais e facilitar a consulta e atualização dos dados.

# 

# \## 2. Objetivo

# 

# O principal objetivo do sistema é disponibilizar uma solução web simples e funcional para apoiar a gestão das principais atividades de uma biblioteca.

# 

# \## 3. Funcionalidades

# 

# O sistema possui as seguintes funcionalidades:

# 

# \- Autenticação de utilizadores;

# \- Login e logout;

# \- Dashboard;

# \- Cadastro de livros;

# \- Listagem de livros;

# \- Pesquisa de livros;

# \- Edição de livros;

# \- Exclusão de livros;

# \- Cadastro de leitores;

# \- Listagem de leitores;

# \- Registo de empréstimos;

# \- Listagem de empréstimos;

# \- Registo de devoluções;

# \- Controlo da disponibilidade dos livros;

# \- Validação dos formulários;

# \- Controlo de acesso às páginas protegidas.

# 

# \## 4. Tecnologias utilizadas

# 

# \- PHP

# \- HTML5

# \- CSS3

# \- JavaScript

# \- MySQL/MariaDB

# \- XAMPP

# \- Apache

# \- phpMyAdmin
